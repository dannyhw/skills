# Word swaps

The first table is adapted from the GOV.UK 'Words to avoid' list. The second maps words that AI-generated text overuses, adapted from the SimpleEnglish project. Neither list is complete. They show the sort of language that slows readers down. If a word carries no fact, delete it instead of replacing it. Most buzzwords disappear when you say what you are actually doing.

## GOV.UK words to avoid

| Avoid | Write instead |
|---|---|
| agenda (except for a meeting) | plan |
| advance | improve, or say what changes |
| collaborate, liaise | work with |
| combat, tackle | stop, solve, fix |
| commit, pledge | plan to, or "we're going to" and a specific verb |
| counter | prevent |
| deliver (except goods) | make, create, provide, or the specific verb |
| deploy (except software or the military) | use, build, put in place |
| dialogue | talk to, discussion |
| disincentivise | discourage |
| empower | allow, let |
| facilitate | say what you are doing: run, host, pay for |
| focus | work on, concentrate on |
| foster (except children) | encourage, help |
| impact (as a verb) | affect, have an effect on |
| incentivise | encourage |
| initiate | start, begin |
| key (as an adjective) | important, main, or delete |
| land (except aircraft) | get, achieve, release |
| leverage (except finance) | use |
| overarching | delete, or "overall" |
| progress (as a verb) | work on, develop |
| promote | recommend, support |
| robust | say what makes it strong: "retries 3 times", "tested on 10,000 files" |
| slim down | reduce |
| streamline | simplify, remove steps |
| strengthen | say what is added |
| transform | describe the change |
| utilise | use |
| drive (a scheme or people) | lead, increase |
| going forward, moving forward | from now on, or delete |
| in order to | to |
| hub, portal, one-stop shop | name the page or service |
| ring-fence | reserve, keep for |

## AI-overused words

| Avoid | Write instead |
|---|---|
| ensure | make sure |
| prior to | before |
| purchase | buy |
| assist | help |
| approximately | about |
| commence | start |
| it is worth noting that, it's important to | delete, then state the fact |
| simply, just, easily, seamless, seamlessly, effortlessly | delete |
| powerful, comprehensive, performant, cutting-edge, state-of-the-art | delete, or give the measured property |
| functionality | feature |
| enables you to, allows you to | you can |
| is designed to, aims to | delete, then say what it does |
| delve into, dive into | read, look at |
| when it comes to | for |
| in the event that | if |
| due to the fact that | because |
| as needed | state the condition |
| and/or | "X, Y or both" |
| gracefully handles | say what it does: "retries 3 times, then stops" |
| out of the box | by default |
| under the hood | internally |
| plethora, myriad | many |
| pivotal, crucial, paramount | important, or delete |
| tapestry, testament, synergy, realm, landscape (as a metaphor) | delete, or "area" |
| intricate, multifaceted, nuanced | complex, or name the parts |
| groundbreaking, innovative, unprecedented, game-changer, revolutionise | new, or say what changes |
| showcase, underscore, emphasise | show |
| bolster, enhance, elevate | improve, increase |
| harness | use |
| furthermore, moreover, additionally | also |
| in conclusion, in summary, at the end of the day | delete |
| embark on, endeavour | start, try |
| meticulous, meticulously | careful, carefully |
| holistic | full, whole |
| navigate (as a metaphor) | go to, find |
| boasts | has |
| that being said, notwithstanding | but |
| please, please note, kindly | delete |
| I hope this helps, let's dive in, happy to help | delete |
