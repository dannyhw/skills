# UK spelling

Use these spellings in prose. Never change code, identifiers, API fields, CLI flags, file names, quoted errors, product names or proper nouns (Pearl Harbor, the World Health Organization, Microsoft Authorization Manager). A word inside backticks is code.

## Patterns

| US | UK | Examples |
|---|---|---|
| -ize, -ization | -ise, -isation | organise, recognise, prioritise, initialise, serialise, authorisation, optimisation |
| -yze | -yse | analyse, paralyse, catalyse |
| -or | -our | colour, behaviour, favour, honour, labour, neighbour, flavour |
| -er | -re | centre, metre (unit), litre, fibre, theatre |
| -og | -ogue | catalogue, dialogue, analogue |
| -ense | -ence | licence (noun), defence, offence, pretence |
| single l before a suffix | double l | cancelled, cancelling, labelled, modelling, travelled, signalled, levelled, fuelled |
| double l | single l | enrol, fulfil, instalment, skilful |
| -e- | -ae- or -oe- | paediatric, anaesthetic, manoeuvre, oestrogen |
| -ment after a soft g | keep the e | judgement, acknowledgement |

Do not change: size, prize, capsize, seize (always -ize). Advertise, advise, comprise, compromise, devise, revise, supervise, surprise (always -ise in both). Meter (a device that measures), as in "a gas meter". Dialog (the UI element, in software text), because the industry uses it as a technical term.

## Words that change with their part of speech

| Noun | Verb |
|---|---|
| licence: "a software licence" | license: "we license the code under MIT" |
| practice: "best practice" | practise: "practise the restore" |
| advice | advise |
| device | devise |

## Words that differ in meaning

| Word | UK use |
|---|---|
| program | Software only: "the program crashed". |
| programme | Everything else: "a training programme", "the release programme". |
| disk | Storage in computing: "disk space". |
| disc | Physical media and anatomy: "a CD", "a slipped disc". |
| tyre, kerb, grey, cheque, aluminium, sceptical, storey (of a building), draught, plough, pyjamas, mould, smoulder | Always UK form. |

## Dates and numbers

Write dates as day, month, year with no ordinals and no comma: 2 June 2026, not June 2nd, 2026. Use the 12-hour clock with no space: 5:30pm. See `style-points.md`.
